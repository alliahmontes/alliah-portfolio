COG Harvest Attendance & Member-Care System

A check-in and follow-up app for ministry leaders and ushers at COG Harvest Church, Taytay, Rizal. It replaced paper sign-ins with a live directory and a dashboard that shows who needs a call this week.

  • Real-time check-in, member directory, service scheduling, and an analytics dashboard for weekly and yearly trends, newcomer retention, and at-risk follow-ups.
  • Role-based access for Admin, Usher, and Leader, enforced with PostgreSQL Row-Level Security, plus a secure Edge Function for admin-only invites.
  • Heavy report math moved into SQL aggregate functions so the dashboard stays fast as attendance grows. Ships as an installable PWA on Vercel.
